# QQ 会议简记插件

本插件的目标是为 QQ 会话提供“开会时的简短记录”，而不是做长期归档或回忆留存。适合会后快速整理归档，不承担合规留痕或长期存档职责。

## 设计思路（概要）
- **存储介质**：仅使用内存缓存，不落盘、不上传，避免历史泄露或误用为归档。
- **缓存模型**：按会话（群聊/私聊）维护独立 `deque`，最多保留最近 500 条记录（默认，可通过命令调整），超出自动丢弃最旧消息。
- **写入路径**：收到消息时格式化为 `内容【来源名称】` 后写入对应会话的缓存；异步锁保证并发安全；支持会话命令开关缓存。
- **读取路径**：`/record [limit]` 与 `/record_file [limit]` 命令直接从内存缓存读取，`limit` 默认 10，最大不超过当前容量上限。
- **安全边界**：不做持久化；`/record_file` 采用临时文件发送后立即删除，避免长期留存。

## 使用提示
- 可用指令：
	- `/record [limit]`：从内存读取并以文本消息返回最近 `limit` 条（默认 10，最大不超过缓存上限）。
	- `/record_file [limit]`：将最近 `limit` 条打包为临时 `.txt` 文件发送，随后自动删除临时文件，避免长消息刷屏。
	- `/record_cache [on|off]`：开启/关闭缓存写入；不带参数显示当前开关与容量。
	- `/record_limit [n]`：设置/查询每会话容量上限（范围 1~5000，默认 500）；调整后会对现有会话进行裁剪。
- 开会时保持插件运行，结束后通过上述指令快速回顾要点。
- 由于只在内存中保留，机器人重启或进程退出后记录即清空。
